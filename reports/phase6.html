Giai đoạn 6 - Hoàn thành

Tích hợp & Kiểm thử toàn bộ luồng

Hướng dẫn kiểm chứng hoạt động của toàn bộ hệ thống phân tán và các kịch bản lỗi, retry.

Học phần: Lập trình API

Hệ thống quản lý Facebook Page

Các kịch bản kiểm thử (Test Scenarios)

Kịch bản 1: Nhận tin nhắn & Phân tích AI & Phản hồi thành công

Gửi comment bình thường, ví dụ: "Shop oi gia bao nhieu". Hệ thống chuẩn hóa, AI nhận diện là ý định hỏi giá (ask_price), backend thực hiện reply lên Facebook và lưu vào database.

Kịch bản 2: Phát hiện spam link & Ẩn tự động

Gửi comment chứa link rác: "Mua ngay tai http://scam.vn". Rule Engine lập tức ẩn bình luận và đánh dấu trạng thái pending_review mà không chạy phân tích AI.

Kịch bản 3: Kiểm soát Rate Limit cục bộ

Gửi liên tục 21 comment trong vòng dưới 1 phút từ cùng một tài khoản. Hệ thống kích hoạt rate limit, toàn bộ comment vượt ngưỡng sẽ không được phân tích AI/reply, tự động đưa vào danh sách duyệt thủ công.

Kịch bản 4: Tự động đưa vào Blacklist nội bộ

Nếu 1 tài khoản spam (chứa link hoặc AI đánh dấu là spam) lớn hơn 3 lần trong vòng 24 giờ, tài khoản đó sẽ tự động bị đưa vào danh sách đen. Mọi comment sau đó sẽ bị phớt lờ (ignored).

Kịch bản 5: Lỗi kết nối & Retry Backoff & Dead Letter Queue

Khi Backend API gọi Facebook API thất bại (ví dụ: mất mạng hoặc Facebook lỗi 500), Backend đẩy lỗi sang send_failed. Retry Service trì hoãn lũy thừa (1s, 2s, 4s, 8s, 16s) và gửi lại. Sau 5 lần thất bại liên tục, đẩy vào dead_letter kích hoạt Slack Alarm.

🚀 Hướng dẫn chạy thử nghiệm bằng Script giả lập

Chúng tôi cung cấp script test_webhook.js tự động tạo chữ ký bảo mật HMAC-SHA256 phù hợp với App Secret để giả lập cuộc gọi từ Facebook.

Chạy thử comment hỏi giá bình thường: 
node test_webhook.js "Shop oi gia bao nhieu"
Chạy thử comment spam link: 
node test_webhook.js "Nhan qua free tai http://scam.org"

Sửa lỗi (#200) Permissions error từ Facebook Graph API

Khi chạy trên comment thật từ Facebook, nếu gặp lỗi OAuthException (200) Permissions error, nguyên nhân chính là do Page Access Token của bạn bị thiếu quyền ghi tương tác.

Quyền bị thiếu: pages_manage_engagement

Token hiện tại của bạn chỉ có quyền đọc tin nhắn/bài viết (pages_read_engagement, pages_manage_posts, pages_manage_metadata). Để bình luận hoặc ẩn bình luận, bắt buộc phải có pages_manage_engagement.

Các bước khắc phục:
  1. Truy cập Facebook Developers Dashboard và chọn App của bạn.
  2. Mở công cụ Graph API Explorer.
  3. Chọn Meta App tương ứng, ở phần User or Page chọn Page của bạn.
  4. Tại phần Permissions, thêm quyền pages_manage_engagement (và pages_manage_posts, pages_read_engagement).
  5. Nhấn Generate Access Token và đồng ý cấp quyền.
  6. Sao chép Page Access Token mới thu được.
  7. Cập nhật token mới vào file services/backend-api/.env tại biến FACEBOOK_PAGE_ACCESS_TOKEN.
  8. Khởi động lại backend API.
