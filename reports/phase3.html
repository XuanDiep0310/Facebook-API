Giai đoạn 3 - Hoàn thành

Nhận sự kiện thời gian thực (Webhook Service - Port 3001)

Đăng ký sự kiện từ Facebook, verify bảo mật HMAC-SHA256 và publish vào Kafka Broker.

Học phần: Lập trình API

Hệ thống quản lý Facebook Page

Các đầu việc đã thực hiện

  • Tách biệt Webhook Service Thiết lập cấu trúc monorepo riêng biệt tại services/webhook-service/, chạy độc lập trên Port 3001 giúp phân tải hệ thống.
  • Xác thực HMAC-SHA256 (Timing Safe) Sử dụng Express body-parser để bắt raw buffer, sau đó băm SHA256 dựa trên App Secret và so sánh bằng phương pháp an toàn crypto.timingSafeEqual để tránh timing attacks.
  • Chuẩn hóa dữ liệu sự kiện (Normalizer) Các payload phức tạp từ Facebook (bình luận, bài đăng, tin nhắn...) được đưa về cấu trúc dữ liệu chuẩn (NormalizedEvent) trước khi đẩy vào Kafka.
  • Kafka Producer với Fallback Auto-Mock Producer tự động kết nối và publish message vào topic raw_events. Nếu mất kết nối Kafka Broker, producer tự động fallback ghi log ra file kafka_mock.log để đảm bảo không bị crash.

📦 Đặc tả Schema Sự kiện chuẩn (NormalizedEvent)

{
  "eventId": "String (uuid hoặc ID của Facebook)",
  "eventType": "comment | message | message_echo | postback | reaction",
  "verb": "created | edited | deleted | received",
  "source": "facebook",
  "pageId": "String (ID trang facebook)",
  "senderId": "String (ID người dùng)",
  "senderName": "String | null",
  "recipientId": "String (ID trang nhận)",
  "postId": "String | null",
  "parentCommentId": "String | null (ID comment cha)",
  "content": "String (nội dung text)",
  "timestamp": "Number (Unix timestamp ms)",
  "rawPayload": "Object (payload gốc dùng để debug)"
}

Cấu hình & Tích hợp

1. Cấu hình Tunnel Ngrok

Sử dụng ngrok để tunnel port 3001 ra ngoài public: .\ngrok.exe http 3001

2. Đăng ký Webhook trên FB Dev

Vào FB Developer Console, điền Callback URL: https://[ngrok-subdomain]/webhook và Verify Token khớp với cấu hình trong file .env.

💻 Khởi chạy Webhook Service

Di chuyển thư mục: 
cd services/webhook-service
Khởi chạy dev server: 
npm run dev
