Xây dựng & Tái cấu trúc Backend API (Port 3000)

Thiết lập Proxy API kết nối Facebook, đảm bảo Idempotency, Circuit Breaker và kết nối Database.

Học phần: Lập trình API

Hệ thống quản lý Facebook Page

Các đầu việc đã thực hiện

  • Tái cấu trúc thư mục & thiết lập dự án con Đã tách backend thành service độc lập tại services/backend-api/ với file package.json và file cấu hình môi trường .env riêng biệt.
  • Tích hợp Opossum Circuit Breaker Thiết lập Circuit Breaker bọc quanh các Graph API calls. Nếu Facebook gặp lỗi liên tiếp hoặc timeout, hệ thống tự động mở mạch (circuit open) để dừng request, tránh làm nghẽn luồng và thử lại sau 30 giây (half-open).
  • Đảm bảo tính Idempotency Tích hợp kiểm tra trùng lặp thông điệp. Khi consume lệnh từ Kafka, backend tra cứu command_id trong bảng idempotency_keys của Postgres. Nếu trùng sẽ lập tức bỏ qua.
  • Winston & Morgan Logger Ghi nhận log của mọi request đến/từ Facebook chi tiết và lưu trữ tại services/backend-api/logs/combined.log.
  • Kafka Consumer & Error Routing Consumer kết nối thành công, lắng nghe reply_commands và send_retry. Nếu gọi Facebook lỗi tạm thời, đẩy thông điệp lỗi sang send_failed để retry.

🔐 Dashboard Admin API (Đã kích hoạt bảo mật)

Các API sau phục vụ dashboard quản trị và yêu cầu truyền Header X-Admin-Key: [API_KEY] để truy cập.

Method Path Mục đích Kiểu trả về
GET /api/admin/dashboard Lấy thống kê số lượng comment theo sentiment, intent và status JSON object tổng hợp
GET /api/admin/comments Lấy danh sách 100 bình luận mới nhất lưu trong database Mảng các comments

Cấu hình của bạn

DATABASE_URL trong .env

Database đã được cấu hình trỏ tới PostgreSQL của Docker Compose. Bạn có thể thay đổi cổng hoặc user nếu dùng cơ sở dữ liệu riêng.

X-Admin-Key

Giá trị admin key hiện tại trong file .env là secret-key. Vui lòng cập nhật trước khi đưa lên môi trường thật.
