Thiết lập hạ tầng phân tán & Docker Compose

Dựng môi trường Kafka, PostgreSQL, Prometheus và Alertmanager cho toàn bộ hệ thống.

Học phần: Lập trình API

Hệ thống quản lý Facebook Page

Các đầu việc đã thực hiện

  • Cấu hình Docker Compose đa dịch vụ Viết file docker-compose.yml tích hợp Kafka (Zookeeper, Kafka Broker), Kafka UI, Kafka Exporter, Prometheus, Alertmanager và PostgreSQL.
  • Thiết lập giám sát Prometheus Cấu hình file prometheus/prometheus.yml tự động scrape metrics từ Kafka Exporter mỗi 15 giây.
  • Định nghĩa luật cảnh báo (Alert Rules) Tạo file prometheus/alert.rules.yml chứa 3 rule: Cảnh báo khi có message vào Dead Letter Queue (critical), Cảnh báo khi consumer lag vượt quá 500 (warning), Cảnh báo khi Webhook không nhận sự kiện 10 phút (warning).
  • Cấu hình Alertmanager với Slack Tạo file alertmanager/alertmanager.yml, tích hợp URL Slack nhận thông báo của bạn. Cảnh báo critical (lỗi DLQ) sẽ được bắn lập tức (group_wait: 0s).

📍 Danh sách các cổng dịch vụ & Link truy cập

Dịch vụ Cổng Địa chỉ truy cập / Kết nối Ghi chú
Kafka Broker 9092 / 29092 localhost:9092 Giao tiếp ngoài container dùng 9092, nội bộ dùng 29092
Kafka UI 8080 http://localhost:8080 Giao diện quản lý topics, consumers và messages
Prometheus 9090 http://localhost:9090 Hệ thống giám sát metrics và kiểm tra alert rules
Alertmanager 9093 http://localhost:9093 Quản lý và định tuyến cảnh báo tới Slack
PostgreSQL 5432 localhost:5432 (fb_api_db) Lưu dữ liệu comment và idempotency keys

Cần cấu hình bổ sung

1. Bật Docker Desktop

Đảm bảo ứng dụng Docker Desktop đang chạy trên máy tính Windows trước khi chạy các lệnh khởi động.

2. Slack Incoming Webhook URL

URL hiện tại đang lấy từ link channel archive của bạn. Nếu cần nhận thông báo alert thực sự trên Slack, vui lòng tạo Incoming Webhook trong Slack App settings và cập nhật vào file alertmanager/alertmanager.yml.

💻 Lệnh khởi động & Kiểm tra

Khởi động tất cả container: 
docker compose up -d
Kiểm tra trạng thái container: 
docker compose ps
Xem logs của Zookeeper/Kafka: 
docker compose logs kafka
