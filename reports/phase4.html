Giai đoạn 4 - Hoàn thành

AI & Tự động hóa (Core Service - Port 3002)

Phân tích cảm xúc bằng Gemini AI API, áp dụng Rule Engine ra quyết định ẩn/trả lời bình luận tự động.

Học phần: Lập trình API

Hệ thống quản lý Facebook Page

Các đầu việc đã thực hiện

  • Xây dựng Core Service độc lập Thiết lập dự án con tại services/core-service/, kết nối Postgres và Kafka Broker. Expose cổng 3002 phục vụ health check.
  • Tích hợp Gemini AI API + Fallback logic Kết nối Gemini API qua thư viện chính thức. Sử dụng prompt kỹ thuật để ép cấu trúc JSON phản hồi chứa intent, sentiment, isSpam. Bọc Circuit Breaker bọc ngoài, nếu lỗi API tự động fallback gán mặc định (neutral, other) để giữ pipeline thông suốt.
  • Chống trùng lặp sự kiện (Dedup) Khi nhận sự kiện từ topic raw_events, hệ thống kiểm tra trạng thái trong bảng comments. Nếu comment đã ở trạng thái đã xử lý thì bỏ qua ngay để không gọi AI và trả lời trùng lặp.
  • Phát triển Bộ luật tự động (Rule Engine) Quyết định hành động dựa trên cảm xúc và ý định:
    • Chứa liên kết/link lạ → Ẩn ngay, trạng thái pending_review.
    • Rate limit (>20 comment/phút) → Tạm dừng gọi AI, đẩy sang duyệt thủ công.
    • Spam lặp lại (>3 lần trong 24 giờ) → Auto-blacklist người dùng, không auto-reply nữa.
    • Cảm xúc tích cực (positive) → Tự động sinh command reply lời cảm ơn.
    • Cảm xúc tiêu cực (negative) → Tự động sinh command reply xin lỗi và hỗ trợ.
    • Hỏi giá (ask_price) → Auto-reply hướng dẫn check inbox.

Cảm xúc / Ý định Hành động của hệ thống Nội dung phản hồi tự động mẫu
Positive (Tích cực) Trả lời bình luận (Reply) "Cảm ơn bạn [Tên] đã để lại phản hồi tích cực! Shop chúc bạn một ngày vui vẻ."
Negative (Tiêu cực) Trả lời bình luận (Reply) "Dạ chào bạn, rất xin lỗi vì trải nghiệm chưa hài lòng. Shop sẽ nhắn tin hỗ trợ bạn ngay lập tức ạ!"

Yêu cầu cấu hình

Đăng ký Gemini API Key

Truy cập Google AI Studio để lấy API Key miễn phí.

Cấu hình file .env

Mở file services/core-service/.env và cập nhật khóa vừa tạo vào trường:

GEMINI_API_KEY=AIzaSy...

💻 Khởi chạy Core Service

Cài đặt dependencies: 
npm install
Khởi chạy dev server: 
npm run dev
